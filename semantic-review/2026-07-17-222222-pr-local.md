Recovery restores the previous pair or reinstalls the next pair before settings/keybindings reads, with file and parent-namespace flushes where supported and renamed-target flushes plus the idempotent phase journal on Windows.

## Exact-preview acknowledgement gates agent decisions

`approveAgent` requires both an acknowledged pending entry and an exact UUID match. `AgentPanel` acknowledges from `useEffect` after the state update commits the requested action and structured diff, so early, run-only, stale, duplicate, and superseded responses cannot release work.

The acknowledgement timeout is bound to the same internal generation. Both settlement paths delete ownership before resolving and clear the timer; supersession, queued or active cancellation, failed delivery, and final teardown all converge there, so delayed acknowledgements cannot reactivate obsolete previews.

## Main-owned scope survives final-leaf and canonical settings paths

`ensureSettingsFile` registers the lexical settings path and `fs.realpath()` identity before `settingsResolve` grants the dedicated Main-owned file capability. `filesystem.writeFile` authorizes first and passes the original request plus canonical target to `writeResolvedSettingsFile`: a final-leaf path matches the lexical identity, while a canonical read path matches the realpath identity.

Managed content is parsed and sanitized through the preference queue, and user-scoped commits immediately refresh Main egress and update policy. Scope is never accepted from generic renderer input.

## Prepared/committed recovery orders the preference pair

The journal carries complete previous and next snapshots. A durable `prepared` phase selects rollback until both replacements finish; a durable `committed` phase then selects rollforward. Recovery is idempotent and removes the journal only after the selected pair is installed, so interruption during recovery repeats the same decision.

Atomic installation flushes temporary contents, the renamed target, and the parent namespace. Journal installation precedes preference replacement, both replacements precede the committed marker, and durable journal removal follows the pair. Windows directory sync returns `EPERM`; retaining target flushes and the recoverable phase marker avoids an unjournaled two-file interval while POSIX-capable filesystems also receive directory fsync ordering.

`readSettings` and `readKeybindings` share the preference FIFO and recover before reading; their writes and managed Settings JSON writes recover through the same boundary.
